# Charm Email OS

Client management platform for email outreach campaigns with AI-powered strategy generation.

## Overview

Charm Email OS manages the full lifecycle of email outreach campaigns:
1. **Client onboarding** via external form → strategy generation
2. **Domain sourcing** with pattern-based generation and approval workflow
3. **Inbox purchasing** through HyperTide automation
4. **Campaign strategy** generated by Claude Code using Cold Email Skill v2.0
