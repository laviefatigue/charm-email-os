## Direction Decision (2026-05-15)

User redirected from "warm-modern Vercel + selective paperclip lifts" → "full paperclip Village aesthetic, lift the whole system." Reasoning: the Village's density model (generous *between* surfaces, dense *inside* surfaces) actually serves operator UIs better than safe-default-shadcn. The three non-negotiables (warm ink, offset shadow as signature, outline-carries-hierarchy) are what prevent the UI from reading as generic AI design.
